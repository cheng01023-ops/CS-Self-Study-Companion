# CS 自学

一款面向 Mac 零基础自学者的 iOS 17+ / macOS 14+ 学习 App。项目使用 SwiftUI、SwiftData 和 Xcode 15+ 可直接打开的工程结构，内置从 Mac 终端到 Linux、C、系统编程、网络、编译器、数据库与专精方向的完整路线。

## 快速开始

1. 双击 `CSSelfStudyCompanion.xcodeproj`。
2. 选择 `CSSelfStudyCompanion` Scheme。
3. 选择 macOS 或任意 iPhone/iPad 模拟器。
4. 按 `Command + R` 运行。

首次运行会自动把课程、练习和 52 条终端/Linux 命令写入 SwiftData。后续启动直接读取本地数据；进度可在“学习进度”页重置。

命令行验证：

```bash
xcodebuild -project CSSelfStudyCompanion.xcodeproj \
  -scheme CSSelfStudyCompanion \
  -destination 'platform=macOS' \
  CODE_SIGNING_ALLOWED=NO build

xcodebuild -project CSSelfStudyCompanion.xcodeproj \
  -scheme CSSelfStudyCompanion \
  -destination 'platform=iOS Simulator,name=iPhone 17 Pro,OS=26.5' \
  CODE_SIGNING_ALLOWED=NO build
```

## 第一部分：App 架构设计

### 数据模型

`Stage` 表示阶段，拥有标题、顺序、图标、主题色和多个 `Topic`。`Topic` 表示主题，包含预计时长、教程和练习。`Tutorial` 保存 Markdown 正文、一到两段 C/Swift/Shell/SQL/Docker 示例以及常见错误。`Exercise` 支持选择题和编程题，并保存参考答案。`Progress` 以 `itemID` 唯一标识教程或练习的完成状态、分数和最近学习时间。`Command` 保存平台、分类、语法、说明、示例和搜索标签。

关系全部由 SwiftData 管理：删除阶段会级联删除主题、教程和练习；学习进度是独立记录，因此课程更新不会覆盖用户数据。

### 页面与导航

- 首页路线图：阶段卡片、总进度、教程与练习统计。
- 阶段详情：主题列表、阶段进度和预计学习时间。
- 主题详情：教程与练习入口。
- 教程页：八阶段、分步骤学习，一次只展示一个步骤，提供固定操作栏、步骤目录、阅读时长提示、阶段学习提示、阅读位置恢复和逐步完成状态。
- 全页面使用统一自适应宽度：窗口变窄时占满可用宽度，全屏时扩展到合适的阅读宽度并自动居中，不会只显示在左半部分。
- 练习页：选择题即时反馈，编程题先独立实现再展开参考答案。
- 知识中心：全局搜索教程、章节、概念、命令、收藏和笔记；支持术语详情、相关教程和同类概念跳转。
- 收藏与笔记：每个学习步骤都可以收藏，可记录个人理解、疑问、实验结果和复习内容。
- 复习中心：错题、主动回忆和长期记忆统一管理，按 1、3、7、30 天自动排期。
- 掌握度与推荐：根据主动回忆、练习、代码判题和复习结果计算概念掌握度，识别薄弱概念并推荐下一步行动。
- 代码工作台：macOS 可直接编辑、编译和运行 C 代码；iPhone 通过同一局域网 Mac companion 远程编译运行，并返回标准输出、错误、退出码和判题结果。
- 项目制课程：6 个可执行项目，包含里程碑、交付物和结业验收。
- 互动实验室：位运算、内存布局、TCP 三次握手和哈希碰撞实验。
- 使用指南：首页、知识中心、复习中心、命令速查和进度页均可打开，覆盖首次上手、学习模式、教程、练习、复习、项目、数据迁移和常见问题。
- 增量同步：同步数据按 SHA-256 指纹检测变化，只在数据变化时发送完整合并备份；设备通过 Bonjour 角色信息区分 Mac 和 iPhone。
- Mac companion：iPhone 可将代码请求发送给同一局域网中的 Mac，Mac 沙盒运行后返回结果。
- 实时同步：同一 Wi-Fi 下使用 MultipeerConnectivity 自动发现 Mac 与 iPhone，并按时间戳双向合并学习数据。
- 教程外部资源：`LearningResource` 与具体教程建立一对多关系；资源区位于学习步骤总览下方，关联官方文档、大学公开课、开源教材和长期维护的免费资料，并附来源、难度、语言、是否免费、解释说明、复制和打开操作。当前 89 条资源覆盖全部 28 篇教程。
- 数据迁移：使用 `AppSchemaV1`、`VersionedSchema` 和 `AppMigrationPlan` 打开 SwiftData 容器；旧数据库启动后自动迁移。
- 自动化测试：工程包含 macOS 单元测试、iOS 单元测试和 iOS UI 测试三个 XCTest Target，并提供两套测试 Scheme 和一键测试脚本；测试覆盖进度、复习、备份加密、内容完整性和代码运行。
- 数据与备份：通过 JSON 导出/导入学习进度、收藏、笔记、错题、复习计划、代码草稿和掌握度，用于 Mac 与 iPhone 之间迁移，支持 AES-GCM 加密。
- 代码运行增加 macOS 沙盒、网络禁用、用户目录访问限制、CPU 时间和输出文件上限。
- 主动回忆支持关键词覆盖评分，复习算法加入难度因子、稳定度和顽固卡点。
- 概念详情支持前置知识依赖，数据备份支持 AES-GCM 加密。
- 搜索采用输入防抖和后台索引，教程支持快速、标准、深度三档学习模式。
- 项目制课程覆盖命令行工具、系统编程、网络、并发和编译原理，并提供可勾选里程碑。
- 互动实验室用控件和状态切换演示抽象概念，减少只看文字的学习成本。
- 命令速查：搜索、平台筛选、分类筛选和示例复制。
- 进度页：总进度、阶段进度、最近完成和重置操作。

导航使用 `NavigationStack(path:)` 与 `AppRoute` 值路由。阶段、主题、教程和练习都只传 ID，页面再从 SwiftData 查询数据，避免把大对象塞进导航值，也方便后续增加深链接。

## 第二部分：核心功能

### 学习路线图

首页按照阶段顺序展示卡片。阶段进度等于已完成主题数除以主题总数；一个主题只有在全部教程和练习完成后才计为完成。进度条同时显示百分比，便于快速判断当前位置。

### 教程渲染

`MarkdownText` 支持标题、段落、无序列表和行内 Markdown。代码块使用独立的 `CodeBlockView`，按语言进行基础语法着色，支持横向滚动、文本选择和一键复制。所有教程正文均为中文，并包含“为什么、怎么做、常见错误”三部分。

### 代码练习

选择题保存选项、答案和解析，作答后立即显示正误。编程题包含起始代码、参考实现和解释，答案可复制到 VS Code、Xcode 或终端编辑器。C 示例默认使用 `clang -Wall -Wextra -g` 编译。

### 命令速查

当前收录 52 条 macOS 终端与 Linux 命令，覆盖目录、文件、权限、Git、编译、进程、systemd、日志、磁盘、网络、文本处理、cron、调试、容器、防火墙和安全模块。支持模糊搜索、平台切换、分类筛选及示例复制。

### 进度持久化

每次打开教程都会更新 `lastStudiedAt`；点击完成按钮后写入 `isCompleted`、`completedAt` 和可选分数。进度页可查看总完成率、阶段完成率和最近完成时间。重置只删除 `Progress` 记录，不删除课程内容。

## 第三部分：学习路线大纲

- 阶段 0：Mac 终端与开发工具。终端启动、文件命令、权限、Homebrew、Git、gcc/clang、VS Code。
- 阶段 1：计算机通识。二进制、十六进制、位运算、CPU/内存/存储、操作系统概念。
- 阶段 2：C 语言基础。变量、类型、控制流、函数、数组、字符串、指针、结构体、文件操作。
- 阶段 3：Linux 基础与 Shell。L0–L8 共九个独立主题，见下一节。
- 阶段 4：数学基础。集合、关系、证明、归纳、线性代数、概率和信息论。
- 阶段 5：计算理论。自动机、形式语言、可计算性、复杂度、算法范式和程序语义。
- 阶段 6：数据结构与算法。复杂度、链表、栈、队列、哈希、树、图、排序、查找。
- 阶段 7：计算机架构与汇编。x86-64、寄存器、栈帧、调用约定、编译链接、缓存。
- 阶段 8：操作系统 + Linux 系统编程。进程、线程、调度、同步、虚拟内存、文件系统、POSIX、fork/exec、pthread、信号、IPC、socket、epoll、mmap、gdb、strace、valgrind。
- 阶段 9：计算机网络。TCP/IP、HTTP、DNS、Socket 编程、抓包、C 语言 HTTP 服务器。
- 阶段 10：编译原理。词法、语法、AST、IR、代码生成。
- 阶段 11：数据库系统。SQL、索引、事务、并发控制、存储引擎。
- 阶段 12：方向专精。嵌入式、后端、内核、安全、iOS/macOS 开发。

## 第四部分：Linux 模块

每个 Linux 主题都包含概念讲解、命令示例、C 或 Shell 代码、选择题、编程题与参考答案、常见错误。正文长度控制在约 1000–2000 字，不超过单主题 5000 字。

- L0 环境搭建：UTM、Docker、云服务器、Ubuntu LTS、SSH 密钥与首次登录。
- L1 基础命令：目录、文件、权限、用户、APT 包管理和最小权限。
- L2 Shell 与文本处理：bash 变量、条件、循环、函数、grep、sed、awk、find、xargs、管道和重定向。
- L3 系统管理：进程、systemd、journalctl、磁盘、网络、cron 与稳定排错顺序。
- L4 系统编程：POSIX、文件 I/O、fork/exec、pthread、信号、IPC、socket、epoll、mmap、gdb、strace、valgrind。
- L5 网络与服务：TCP/IP、HTTP、DNS、Nginx 反向代理、UFW 防火墙和 tcpdump。
- L6 内核与性能：/proc、/sys、内核模块、perf、strace、性能基线和 dmesg。
- L7 容器与云：Docker、namespace、cgroup、volume 与 Kubernetes 入门。
- L8 安全：SSH 密钥加固、防火墙、SELinux/AppArmor、日志审计和最小权限。
