# CS 自学 - 使用指南

## 1. 第一次打开

首次启动会出现“入学诊断”，包含终端、C 语言、Linux、数据结构和操作系统五组问题。选择最接近当前情况的答案，系统会推荐从阶段 0 到阶段 3 中的某一阶段开始。这个结果只是推荐，不会锁定课程，之后可以自由进入任何阶段。

如果暂时不想做诊断，可以点击“跳过”，默认从阶段 0 开始。

## 2. 首页与今日计划

首页显示学习路线、总进度、今日建议和“今日三步计划”。

今日三步计划会自动组合：

1. 到期复习。
2. 掌握度较低的概念。
3. 下一篇尚未完成的教程。

计划总时间默认为约 60 分钟，每个任务会显示建议耗时。点击任务可以直接进入对应教程或概念页面。

## 3. 教程与分步学习

阶段和主题按基础依赖排序。进入教程后不会一次显示完整长文，而是分成开始、理解、实践、进阶、巩固、强化、融会、大师等步骤。

教程支持快速、标准、深度三种模式：

- 快速：核心理解与基础实验。
- 标准：包含实践、工程和巩固。
- 深度：展开大师挑战与更多扩展内容。

每完成一步，底部会记录完成状态。退出后再进入，会自动恢复到上次步骤。

## 4. 配套免费资源

每个教程的步骤总览下面都有“配套免费资源”。每条资源包含来源、难度、语言和解释说明。

资源支持：

- “阅读”：在 App 内打开网页，方便返回原教程。
- “浏览器”：使用系统浏览器打开，适合需要登录的网站。
- “稍后看”：把资源加入待阅读状态。
- “标记完成”：记录资源已学习。
- 书签图标：收藏资源。

资源状态和收藏会进入统一进度，并随 Mac/iPhone 同步。

## 5. 主动回忆与笔记

阅读教程前可以先用自己的话回答问题。系统会根据关键词覆盖情况判断理解程度，并决定是否加入复习。

右上角可以：

- 收藏当前教程步骤。
- 写学习笔记、疑问和实验结果。
- 从收藏或笔记返回原步骤。

## 6. 代码练习

代码工作台支持编辑代码、填写标准输入、选择测试用例、编译运行和自动比较输出。

macOS：

- 直接使用本机 clang/swiftc 编译。
- 通过 sandbox-exec 禁用网络、限制用户目录访问、CPU 时间、输出大小和文件写入。

iPhone：

- 让 iPhone 和 Mac 连接同一 Wi-Fi。
- 两台设备都打开 App，并允许本地网络访问。
- iPhone 会把代码请求发送给 Mac。
- Mac 在沙盒中编译运行，再把标准输出、错误、退出码和判题结果返回 iPhone。
- 没有连接 Mac 时，仍可以编辑、保存草稿和复制代码。

## 7. 复习中心

答错的选择题、主动回忆、编程题和需要重做的内容可以进入复习中心。

复习间隔为 1、3、7、30 天。系统同时记录：

- 正确连续次数。
- 遗忘次数。
- 难度因子。
- 记忆稳定度。
- 回答耗时。
- 顽固卡点。

## 8. 知识中心与命令速查

知识中心可以搜索教程正文、章节、概念、命令、收藏和笔记。概念详情会显示前置知识和相关教程。

命令速查支持：

- macOS/Linux 平台筛选。
- 分类筛选。
- 关键字搜索。
- 一键复制命令和示例。
- 直接在 macOS 终端中理解命令用途。

## 9. 项目与互动实验

项目制课程包含命令行工具、文件校验、迷你 Shell、TCP 聊天室、并发任务池和表达式编译器。每个项目包含目标、里程碑、交付物和结业验收。

互动实验室包含位运算、内存布局、TCP 三次握手和哈希冲突实验。

## 10. 学习提醒

在“学习进度”页面开启“每日学习提醒”，选择每天提醒时间即可。首次开启需要允许通知权限。

提醒可以随时修改时间或关闭。

## 11. Mac 与 iPhone 同步

让两台设备连接同一 Wi-Fi，并同时打开 App。

同步内容：

- 学习进度。
- 教程阅读位置。
- 收藏和资源状态。
- 学习笔记。
- 错题和复习计划。
- 代码草稿。
- 概念掌握度。

同步采用数据指纹检测，只在数据发生变化时发送。设备之间按记录时间合并，较新的记录优先。

## 12. 数据备份与迁移

在“学习进度 → 数据与备份”中：

- 导出普通 JSON。
- 导出 AES-GCM 加密备份。
- 导入 Mac 或 iPhone 的备份。
- 使用 AirDrop、文件 App 或 iCloud Drive 手动转移数据。

课程数据库使用版本化 SwiftData Schema。升级 App 时会自动迁移，教程、资源、进度和学习记录会保留。

## 13. macOS 快捷键

- `Command + 1`：学习路线
- `Command + 2`：知识中心
- `Command + 3`：复习
- `Command + 4`：命令速查
- `Command + 5`：学习进度
- `Command + Shift + /`：打开使用指南
- `Command + Return`：在代码工作台编译并运行

## 15. 教回去评估

教程步骤里的“教回去”不再只统计关键词，而是从五个维度评估：

- 概念覆盖
- 原因与因果
- 例子与实验
- 表达结构
- 完整程度

点击“评估并保存”后，系统会给出分数、优势和需要补充的地方，并把解释和反馈保存为独立学习记录。达到 60% 后可以进入掌握和复习流程，未达到会建议补充说明或加入复习。

## 16. Mac 菜单栏常驻代理

Mac 版关闭主窗口后仍会保留在菜单栏，显示同步状态和最近一次远程运行摘要。

菜单栏可以：

- 打开主窗口。
- 立即执行同步。
- 开关“允许 iPhone 远程运行代码”。
- 退出 Mac Companion。

关闭主窗口不会断开局域网同步，因此 iPhone 仍然可以请求 Mac 编译代码。

## 17. Mac 代码执行安全

Mac 远程运行采用原生资源限制启动器和 sandbox-exec：

- 禁止网络访问。
- 禁止访问用户目录和修改系统目录。
- 禁止用户程序调用 shell 或 fork。
- 最多运行 4 秒 CPU。
- 最多使用 256 MB 内存。
- 输出和文件写入上限为 2 MB。
- 代码上限 200 KB。
- 标准输入上限 64 KB。
- 命令行参数最多 16 个。
- 每分钟最多处理 10 次远程运行请求。

如果 Mac 端关闭远程执行，iPhone 会收到明确提示，但不会影响普通学习数据同步。

## 18. 常见问题

### 不知道从哪里开始

完成首次入学诊断，然后从首页“今日三步计划”开始。

### 教程太长

切换快速模式，先完成当前步骤的核心实验，再进入下一步。

### iPhone 无法运行代码

确认 Mac 和 iPhone 在同一 Wi-Fi、两台设备都打开 App，并允许本地网络访问。Mac 版必须保持运行。

### 数据没有更新

检查两台设备是否在同一 Wi-Fi，并等待同步状态显示已连接。必要时在进度页点击“立即同步”。

### 备份导入失败

确认密码和导出时一致。如果使用旧备份，仍可导入；系统会保留新增数据字段的默认值。


## 22. 性能与发布检查

学习进度页包含：

- “性能与稳定性”：查看数据库大小、打开耗时、同步耗时和运行指标。
- “发布就绪检查”：检查版本、Bundle ID、深链接、本地网络权限、图标和签名状态。
- 首页默认显示当前附近的 4 个阶段，可展开全部阶段，避免一次加载过长页面。

正式公开分发：

- iOS 需要 TestFlight 或 App Store。
- macOS 公共分发需要 Developer ID 签名和 Apple 公证。
- Personal Team 免费签名只适合自己的开发设备。
