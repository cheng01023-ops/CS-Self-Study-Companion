## 四、本轮发现并修复的问题

1. 测试注入参数与通知方法重名，导致 App 无法编译。
   - 已重命名为 `schedulesNotification`。

2. 学习数据备份没有保存和恢复复习项的 `dueAt`、难度因子、稳定度和答题耗时。
   - 已加入向后兼容的可选字段并恢复这些值，旧备份仍可读取。

3. 测试中只保留 `ModelContext` 而没有保留 `ModelContainer`，导致容器释放后 SwiftData 崩溃。
   - 已修正测试生命周期。

4. 桌面开发目录最初没有同步新测试 Target。
   - 已同步到 iOS 和 macOS 两套完整源码。

## 五、如何运行

在桌面开发目录双击：

`运行全部测试.command`

脚本会自动：

1. 运行 macOS 全部单元测试。
2. 查找可用的 iPhone 模拟器。
3. 运行 iOS 单元测试和 UI 测试。
4. 将完整日志写入源码目录下的 `work/test-results-时间戳/`。

也可以在 Xcode 中直接选择对应测试 Scheme 后按 `Command + U`。

## 八、后续高优先级改造

- 新增 `AppSchemaV1` 和 `AppMigrationPlan`，SwiftData 数据库改为版本化管理。
- 同步改为 SHA-256 增量指纹发送，数据未变化时不再重复广播完整备份。
- 新增 Mac/iPhone 设备角色发现，iPhone 只能把代码请求发送给 Mac，避免其他 iPhone 抢答。
- iPhone 代码工作台可通过 Mac companion 编译运行 C/Swift 代码，并返回标准输出、错误、退出码和判题结果。
- 每篇教程的外部资源支持“稍后看”“已完成”“收藏”和应用内阅读。
- 首页新增今日三步计划，根据复习、薄弱概念和下一篇未完成教程生成约 60 分钟任务。
- 新增首次入学诊断，根据五道问题推荐起始阶段。
- 新增每日学习提醒，可配置固定时间和开关。
- macOS 新增菜单和快捷键：⌘1 至 ⌘5 切换主页面，⌘⇧/ 打开使用指南。
- App 内置使用指南已同步更新全部新功能。


## 九、数据库恢复保护

- App 不再在数据库打开失败时直接 `fatalError`。
- 失败时自动备份 `default.store`、`-wal` 和 `-shm` 到 `DatabaseRecovery` 目录。
- 新增恢复界面，支持重试打开、查看备份位置和备份后重建新数据库。
- 增加数据库备份单元测试。


## 十、记录级增量同步

- 同步首次连接仍发送完整快照，后续只发送发生变化的记录。
- 新增 `SyncDelta`、`SyncDeletion` 和 `SyncDeltaService`。
- 支持进度、收藏、笔记、复习项、代码草稿和掌握度的变更识别。
- 删除记录使用墓碑和删除时间，远端只有在本机记录不更新时才会删除。
- 增加增量变更、删除墓碑、delta 编解码和合并测试。

- 新增 macOS 菜单栏常驻代理。
